# Product

## Register

brand

## Users

Gleam developers evaluating terminal UI polish. They are likely building CLIs, developer tools, build output, logs, or documentation examples, and they want terminal output that feels designed without making their code impure or hard to test.

## Product Purpose

spruce is a terminal-UI kit for Gleam: styled text, boxes, semantic messages, icons, deterministic hash-colors, ANSI-aware alignment, tables, lists, trees, Markdown rendering, and grouped output. The site should quickly prove that spruce produces real, readable, adaptive terminal output across color support levels and both Erlang and JavaScript targets. Success means a visitor understands the value, trusts the library's craft, and either installs spruce with `gleam add spruce` or opens HexDocs.

## Brand Personality

Precise, calm, and craft-forward. The brand should feel terminal-native and technically confident without sliding into hacker-cliche neon, fake complexity, or novelty aesthetics. The voice is direct, practical, and quietly polished: show real output, explain the composable model, and let the examples carry the quality bar.

## Anti-references

Avoid generic SaaS landing-page tropes, gradient-text gloss, noisy hacker neon, and fake terminal mocks. Do not make the interface feel like a productivity-app template with terminal decoration pasted on top. Every terminal panel should represent real spruce output or a clearly useful code example, not ornamental chrome.

## Design Principles

1. Real output earns trust.
2. Calm craft beats spectacle.
3. Adaptivity is the story, not a footnote.
4. Keep the developer path short: understand, install, read docs.
5. The marketing surface should demonstrate the library's values: composable, pure, readable, and target-safe.

## Accessibility & Inclusion

Use WCAG AA as the baseline. Preserve readable contrast in both dark and light themes, make interactive controls keyboard-friendly and screen-reader legible, and provide reduced-motion behavior for all animation. Terminal examples should remain understandable when color is absent or reduced.
